# Sistema Web de Avaliação Atitudinal

Sistema web desenvolvido com o objetivo de apoiar o acompanhamento pedagógico e a avaliação atitudinal de estudantes do Ensino Básico.

A plataforma busca transformar observações comportamentais e socioemocionais em informações estruturadas, facilitando o acompanhamento individual e coletivo dos estudantes e auxiliando a tomada de decisões pedagógicas.

## Objetivo

Desenvolver um protótipo interativo de um sistema de avaliação atitudinal, considerando diferentes perfis de usuários e suas necessidades de acompanhamento.

## Perfis de usuário

- **Professor:** registro de observações, consulta ao histórico e realização de devolutivas.
- **Coordenação pedagógica:** acompanhamento de indicadores, análise de turmas e identificação de possíveis necessidades de intervenção.
- **Estudante e responsáveis:** acompanhamento da evolução, consulta de devolutivas e participação no processo avaliativo.

## Como executar

O protótipo está disponível online e pode ser acessado diretamente pelo navegador.

### Acessar o sistema

1. Acesse o [Sistema Web de Avaliação Atitudinal](https://sistema-avaliacao-atitudinal-src.vercel.app/).
2. Na tela de login, utilize uma das credenciais de demonstração:

| Perfil | E-mail | Senha |
|---|---|---|
| Professor | `professor@escola` | `123456` |
| Aluno | `aluno@escola` | `123456` |

3. Após o login, você será direcionado para a interface correspondente ao perfil selecionado.

**Observação:** o sistema é um protótipo acadêmico que utiliza dados fictícios. Algumas telas e funcionalidades ainda estão em desenvolvimento.
